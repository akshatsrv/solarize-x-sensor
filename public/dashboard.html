          Connect a Windows kiosk

          1. Enroll the device under Destinations and copy the generated kiosk.env to the device.
          2. Run the preflight from the project folder on the kiosk.
            node --env-file=kiosk.env scripts/doctor.mjs
          3. Start the kiosk agent and check its connection under Destinations.

          For production, kiosks connect to the server over outbound HTTPS. The kiosk display and sensor listener use local loopback.

          POC walkthrough

          1. Preview a presentation using the demo template.
          2. Schedule the presentation for a test kiosk.
          3. Start the display and simulate an arrival and departure under Destinations.
          4. Confirm plays and the check-in trigger in Playback history.
